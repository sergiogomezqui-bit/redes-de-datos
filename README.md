# Redes de Datos — UAO

Repositorio de seguimiento del curso **Redes de Datos** (Universidad Autónoma de Occidente). Contiene notas y ejercicios propios a medida que se van resolviendo; el material de clase (diapositivas, PDFs) pertenece al profesor y no se publica aquí por derechos de autor.

## Temario cubierto

- Introducción a los datos y a las redes de datos
- Clasificación de las redes de datos
- Modelo OSI y modelo TCP/IP
- Organismos de estandarización
- Medios de transmisión y modos de transmisión
- Topologías de red
- Ethernet
- Direccionamiento IPv4 y diseño de subredes (VLSM — subredes de distinto tamaño)
- Direccionamiento IPv6 y coexistencia IPv4/IPv6
- Enrutamiento estático y dinámico
- NAT y PAT
- ICMP
- Protocolos de capa de transporte
- Protocolos de capa de aplicación
- Conceptos básicos de modulación
- WiFi
- Puertos y números de puerto (well-known ports)
- ARPANET (contexto histórico)

## Prácticas

Los ejercicios propios (diseño de subredes, simulaciones en Packet Tracer, talleres) se agregarán en carpetas separadas dentro de este repo a medida que se vayan entregando y resolviendo.
